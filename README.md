# prc-db

Sample PRC (Product Representation Compact) data (test cases) for [prc-rs](https://github.com/ralovich/prc-rs).

## PRC Test Data

Test data is currently very scarce, many parts (structures) of the PRC standard are not yet found in existing test data. If you can, please submit new data (sample 3D PDFs) to increase the coverage. The script [extract3d.sh](https://github.com/ralovich/prc-rs/blob/main/scripts/extract3d.sh) may be used to find and dump PRC and U3D streams from a PDF file.

## Credits

The original PDF data comes from public web searches. Original file names were kept and appended the extracted stream id by [extract3d.sh](https://github.com/ralovich/prc-rs/blob/main/scripts/extract3d.sh). The following web searches appear to surface 3D PDFs:
- 3D pdf datasheet filetype:pdf
- "This is a 3D-PDF. Currently 3D content is not active." filetype:pdf
- "Enable 3D View" filetype:pdf
- "Bill Of Materials" 3D view filetype:pdf
- "This area requires a 3D PDF enabled viewer" filetype:pdf
- "To activate the interactive 3D view" filetype:pdf
- "Click to activate 3D content" filetype:pdf
- "SimLab Generated PDF" filetype:pdf
- "PDF3D Document" filetype:pdf
